주간 회의록 자동화

슬랙 대화에서 아젠다를 뽑고, 회의 녹화로 내용을 기록하고,
Claude가 보고체 회의록까지 완성합니다.

본인이 쓰는 도구를 선택하고 따라하세요.

이 세션에서 만드는 것

매주 누군가가 회의록을 쓰고 있다면, 그 시간을 없앨 수 있습니다.
슬랙 대화 → 아젠다 초안, 회의 녹화 → 텍스트 변환, Claude → 보고체 완성까지 전 과정을 자동으로 이어붙입니다.

왜 Claude인가요?

Claude는 슬랙 MCP로 채널 대화를 직접 읽을 수 있습니다. 별도 연동 개발 없이 "이번 주 #팀채널 대화에서 아젠다 뽑아줘"라고 하면 됩니다.

회의 스크립트(텍스트)를 붙여넣으면 진행상황, 결정사항, 후속 아젠다를 한 번에 뽑아주고, 차상위 보고체까지 변환합니다.

전체 자동화 흐름
1 아젠다 추출
2 회의 녹화
3 스크립트 분석
4 보고체 완성
1

슬랙 대화에서 아젠다 뽑기

회의 전 · 자동

Claude가 슬랙 채널 대화를 읽고 이번 주 논의할 아젠다를 정리합니다. 미리 슬랙에 공유해두면 팀원들이 회의 전 맥락을 파악할 수 있습니다.

입력 #team-devex 이번 주 대화 → 슬랙 MCP로 자동 수집
출력 아젠다 3~5개 + 소요시간 → 슬랙 채널에 자동 발송

💡 Claude.ai 설정 → 연결된 앱 → Slack 활성화 필요

2

회의 중 자동 녹화

회의 중 · 자동

구글밋 또는 슬랙 허들에서 녹화를 켜두면 됩니다. 별도로 할 일은 없습니다.

도구 Google Meet → 내장 자막 + 녹화 기능
도구 Granola → STT 자동 변환 + 구글 드라이브 저장
도구 Whisper API → 정확도 높은 음성→텍스트 변환
3

스크립트 → 진행상황 + 후속 아젠다

회의 후 · 자동

변환된 회의 스크립트를 Claude에 붙여넣으면 핵심만 추려줍니다.

아래는 오늘 팀 회의 녹취록입니다. 다음 세 가지를 뽑아줘. 1. 아젠다별 논의 결과 및 현재 진행 상황 2. 결정된 사항 (담당자 + 기한 포함) 3. 다음 주 후속 아젠다 [스크립트 붙여넣기]

보고체 회의록 완성 + 자동 발송

회의 후 · 자동

3단계 결과를 바탕으로 차상위 조직장에게 보고하는 슬랙 메시지를 자동으로 완성합니다.

위 내용을 차상위 조직장에게 보고하는 형식으로 바꿔줘. - 톤: 간결하고 사실 중심 - 구성: 이번 주 주요 진행 / 결정 사항 / 다음 주 계획 - 분량: 슬랙 메시지 기준 20줄 이내
IDE 및 파일 세팅
폴더 구조

실습 전에 아래 구조로 폴더를 만들어두세요. 깃헙에서 클론하면 바로 사용할 수 있습니다.

meeting-auto/ ├── CLAUDE.md # 프로젝트 컨텍스트 + 규칙 ├── prompts/ │ ├── 01_agenda_extract.md # 슬랙 → 아젠다 │ ├── 02_transcript_analyze.md # 스크립트 → 요약 │ └── 03_report_format.md # 보고체 변환 ├── skills/ │ ├── SKILL.md # 스킬 정의 (트리거 + 톤) │ ├── report-style.md # 보고체 작성 스타일 가이드 │ └── meeting-format.md # 회의록 포맷 템플릿 ├── samples/ │ ├── sample_slack_thread.txt # 슬랙 대화 샘플 │ └── sample_transcript.txt # 회의 스크립트 샘플 └── output/ # 완성된 회의록 저장
CLAUDE.md

프로젝트 루트에 두는 Claude 전용 컨텍스트 파일입니다. Claude Code나 Claude.ai에서 이 프로젝트를 열면 자동으로 읽어서 맥락을 파악합니다.

# 주간 회의록 자동화 이 프로젝트는 테크DevEx팀 주간 회의록을 자동으로 생성합니다. ## 흐름 1. 슬랙 채널 대화 → 아젠다 추출 2. 회의 녹화 스크립트 → 진행상황/결정사항/후속 아젠다 추출 3. 위 결과 → 차상위 조직장 보고체로 변환 ## 규칙 - 보고체는 간결하고 사실 중심. 20줄 이내. - 아젠다는 3~5개, 각각 배경과 소요시간 포함. - 결정사항에는 반드시 담당자 + 기한을 붙인다. - skills/ 폴더의 스타일 가이드를 따른다. ## 참고 - prompts/ : 단계별 프롬프트 템플릿 - skills/ : 작성 스타일 + 포맷 규칙 - samples/ : 테스트용 샘플 데이터
skills/

스킬은 Claude가 특정 작업을 일관되게 수행하도록 만드는 가이드 파일입니다. 프롬프트와 다른 점은, 매번 붙여넣지 않아도 프로젝트에 넣어두면 자동으로 참조된다는 것입니다.

파일 SKILL.md → 스킬 트리거 조건 + 톤 + 동작 규칙 정의
파일 report-style.md → 보고체 톤, 문장 길이, 구성 규칙
파일 meeting-format.md → 회의록 섹션 구조 + 예시 템플릿
# skills/SKILL.md 예시 name: weekly-meeting-report description: | "회의록 작성해줘", "이번 주 회의 정리해줘", "보고체로 바꿔줘" 등의 요청이 오면 이 스킬을 사용한다. ## 톤 - 간결하고 사실 중심. 수식어 최소화. - "~했습니다" 체 기본. 감정 표현 없음. ## 구성 - 이번 주 주요 진행 - 결정 사항 (담당자, 기한 필수) - 다음 주 계획 ## 제약 - 슬랙 메시지 기준 20줄 이내 - 불릿 남발 금지. 항목당 1~2문장으로 서술.
